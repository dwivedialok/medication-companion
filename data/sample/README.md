# Sample prescription images (local only)

No prescription images are committed to git.

For manual smoke tests, add your own file here (gitignored except this README):

```bash
cp ~/Downloads/my-prescription.jpg data/sample/prescription.jpg
export RX_IMAGE=data/sample/prescription.jpg
```
